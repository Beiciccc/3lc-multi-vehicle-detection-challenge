Topic #704140: Installation instruction changes for `3lc` 3.0.0 and 2.23.0
  Author: Kelly Walker
  Posted: 2026-06-03 15:29:33.405000
  Votes: 0  Comments: 0

Note: 3lc 2.23.0 is backwards compatible with recent versions competitors may already be using, whereas 3lc 3.0.0 has breaking changes.

The latest releases of the 3LC Python Package are hosted on 3LC’s own Python package index instead of pypi.org, which means the installation commands have changed and now require some additional parameters. The example commands below should work for installation in a fresh environment. Add -U to upgrade to the latest version as usual or specify the version explicitly (e.g. 3lc==2.23.0). 

uv:

uv pip install --index-url https://pypi.3lc.ai/public/repositories/releases-public --extra-index-url https://pypi.org/simple --index-strategy unsafe-best-match 3lc

pip:

pip install --index-url https://pypi.3lc.ai/public/repositories/releases-public --extra-index-url https://pypi.org/simple 3lc
